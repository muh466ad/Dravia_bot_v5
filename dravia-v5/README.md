## 📋 Command List

### 🆔 Registration (REQUIRED)
- `/register` — Become citizen
- `/citizenid` — View ID card
- `/id renew` — Renew expired ID (20 Drav)
- `/id check @user` — Verify ID [Police]
- `/id suspend @user` — Suspend citizenship [Judge]
- `/id flag @user` — Add warning [Police]

### 💰 Economy
- `/balance` — Check wallet + vault
- `/pay @user 100` — Send money
- `/deposit 100` — Move to vault
- `/withdraw 100` — Take from vault
- `/welfare` — Claim 50 Drav (once/week, if unemployed)
- `/leaderboard` — Richest citizens
- `/history` — Transaction history

### 🏛️ Government (Admin)
- `/gov give @user 500` — Pay from treasury
- `/gov hire @user "Police" 300` — Add to payroll
- `/gov fire @user` — Remove from payroll
- `/gov salary` — Pay all employees weekly
- `/gov treasury` — View balance

### 🏪 Marketplace
- `/market browse` — See all listings
- `/market sell` — List item (5 Drav fee)
- `/market buy [id]` — Purchase

### 🏪 Shop
- `/shop browse` — Government shop
- `/shop buy [id]` — Purchase item

### 🪪 Profile
- `/profile` — View citizen card
- `/inventory` — Your items

### ⚖️ Court
- `/fine @user 100` — Issue fine [Judge]

### 🎲 Gambling (Bet Limits!)
- `/coinflip 50 heads` — Max 100 Drav
- `/rob @user` — Max steal 100 Drav
